# Происхождение изменений

Благодарим авторов смежных проектов за код, исследование API и воспроизводимые
описания проблем. При переносе учитывается лицензия конкретного источника.

## TLS и настраиваемый CA bundle

Код Config/transport и исходные регрессионные тесты адаптированы из
[excuzivedeveloper/rzd-api, 319c090](https://github.com/excuzivedeveloper/rzd-api/commit/319c090c2d7ce005ffe9e4b96e192d487691dc59)
автора **excuzivedeveloper**, MIT. Автор сохранён в отдельном коммите переноса.
Последующие изменения добавляют проверку пути и приоритет явно заданного CA
над окружением Requests. Из этого же исследования взята необходимость tzdata
для Windows.

## Контракты API и модели результатов

[visavi/rzd-api, bb565e1](https://github.com/visavi/rzd-api/tree/bb565e1ad520f61924c6c2b79043c8fccd777456)
автора **visavi / Alexander Grigorev** помог сопоставить ISDK-подсказки, верхний
уровень TrainPricing, местное/московское время и варианты TrainRoute.
Использованы публично описанные контракты и наблюдения API; PHP-код не копировался.
Python-реализация и синтетические регрессионные данные написаны в этом проекте.

## ActualMovement

[OvaleZ/rzd-api, e117722](https://github.com/OvaleZ/rzd-api/commit/e1177223d28c9e4d1edbafab7469a4529707f548),
MIT: исправление неboolean ActualMovement и описание воспроизведения.
В Python адаптирована нормализация только этого необязательного поля;
общий boolean-парсер остаётся строгим.

## Компактные MCP-ответы и пустой календарь цен

[slavb18/rzd-api, b19e13b](https://github.com/slavb18/rzd-api/tree/b19e13bc2665d75de4a9948abb7ba80d6018e14d)
автора **slavb18**, MIT: подход `include_raw` по запросу и различение явного
null-ответа минимальных цен и отсутствующего поля схемы.
MCP-сериализатор здесь работает непосредственно с dataclass и пропускает raw
до копирования, сохраняя полные Python-модели.
